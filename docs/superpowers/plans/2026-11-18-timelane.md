# TimeLane 구현 계획

> 실행 방식: `superpowers:executing-plans`에 따라 현재 세션에서 순차 구현하고 마지막에 독립 코드 리뷰를 수행합니다.

**목표:** World Time Buddy의 시간대 비교와 일정 조율 기능을 로컬 웹앱으로 제공합니다.

**아키텍처:** 브라우저 ES 모듈과 정적 파일만으로 동작하며 Node.js 표준 라이브러리 서버는 루프백 주소에서 정적 파일만 제공합니다. 시간 계산, 위치 검색, 상태 검증, 캘린더 처리를 UI와 분리합니다.

**기술:** Node.js 22 이상, HTML, CSS, JavaScript, Intl/IANA, node:test. 설치 의존성 없음.

**요구 근거:** 사용자의 World Time Buddy 로컬판 구현 요청과 TimeLane 명명 및 진행 지시. https://www.worldtimebuddy.com/features (2026-11-18 확인).

## 범위와 가정

- 도시/시간대 검색, 추가·삭제·이름 변경·정렬·홈 지정, 그룹 관리.
- 실시간 시계, 날짜 이동, 12/24/현지 형식, 시차·날짜·DST 전환 안내.
- 공통 시간축, 마우스 드래그와 키보드 구간 선택, 5분 단위 조정, 개인별 업무시간·주말 표시.
- 일정 제목·메모, 일정 복사, ICS 다운로드, Google/Outlook 일정 작성 링크, 메일 초안, URL 해시 공유.
- 브라우저 저장과 JSON 백업/가져오기, 로컬 ICS 일정 겹쳐 보기.
- 외부 로그인·클라우드 동기화·공개 이벤트 호스팅·Google Calendar 실시간 조회는 로컬 저장, 공유 링크, ICS 가져오기로 대체합니다.
- 서버는 127.0.0.1에만 바인딩하며 소스/문서 파일을 외부에 제공하지 않습니다.
- 사용자 요청 없이 Git 초기화·커밋·푸시·배포를 하지 않습니다.

## 파일 경계

- `src/time.js`: 시간대 계산, DST, 날짜·시각 표시, 시간축.
- `src/locations.js`: 주요 도시 메타데이터와 전체 지원 IANA 시간대 검색.
- `src/state.js`: 상태 생성·검증·백업·공유 링크.
- `src/calendar.js`: ICS 내보내기·가져오기, 일정 공유 데이터.
- `src/app.js`, `src/styles.css`, `index.html`: 화면과 사용자 상호작용.
- `server.mjs`, `start.ps1`, `start.cmd`: 안전한 로컬 실행.
- `tests/*.test.js`: 시간·상태·캘린더·HTTP 경계 검증.
- `README.md`: 실행, 사용, 저장·개인정보, 원본 서비스와의 차이.

## 검토 중점

1. DST 전환일의 23/25시간, 존재하지 않거나 중복되는 현지 시각.
2. 30분·45분 시차, 자정·날짜변경선 및 홈 변경 시 절대시각 보존.
3. 손상된 저장/공유 데이터, HTML 문자열, 과대 파일과 잘못된 입력.
4. 드래그 종료 누락, 터치 스크롤과 키보드 접근성, 좁은 화면.
5. 캘린더 반복 일정의 지원 범위를 숨기지 않고 가져오기 결과 안내.

## 진행 기록

- 초기 조사: WorldTime은 빈 폴더이며 Git 저장소가 아닙니다.
- 판단: 사용자의 진행 지시에 따라 위 기본값으로 연속 구현합니다. Git 전제의 작업 트리/커밋 절차는 적용하지 않습니다.
- 폴더 이름 변경: 다른 프로세스 사용 오류로 실패했습니다. TimeLane 폴더를 새로 만들었고 빈 WorldTime은 보존했습니다. 완료 전 재확인합니다.

- 작업 1~4 완료: 도메인 회귀 테스트 31개 통과, 전체 JS 문법 검사, HTTP 및 브라우저 수동 검증을 수행했습니다.
- 독립 리뷰에서 발견한 공유 덮어쓰기, 날짜 상한/건너뛴 날짜, 부분 시간 칸, 잘못된 시각 편집, ICS 대소문자·종일·알림·순간 일정, 터치 손잡이/포인터 문제를 수정했습니다.
- 판단: 야간 근무는 시작한 요일에 귀속합니다. 종일 DATE+TZID는 RFC에서 금지되므로 지원하지 않습니다.
- 브라우저 검증: 1440px/390px, 검색·45분 시차·홈·그룹·12/24 형식·설정 유지·복사·공유 격리·DST 입력 복원·30분 칸 정렬·마우스 드래그·ICS/JSON 가져오기 확인. 실제 터치 하드웨어 검증은 하지 못했습니다.
- 기본 화면은 테스트 후 4개 도시와 한 그룹으로 복원했습니다.
- 폴더 상태: 원래 빈 WorldTime 폴더는 프로세스 잠금으로 이름 변경에 실패했습니다. 후속 빈 폴더 정리와 검증용 프로세스 종료를 묶은 명령은 자동 승인 검토가 정책상 차단하여 폴더를 보존했습니다. 실제 소스는 TimeLane에 있습니다.
- 전체 Git 저장소가 없으므로 diff 대신 신규 파일과 변경 경계를 자체 검토했고, 요청하지 않은 Git 초기화/커밋/푸시/배포를 수행하지 않았습니다.

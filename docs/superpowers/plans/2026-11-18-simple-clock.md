# 단순 세계 시계 개편 계획

**목표:** 도시별 시간 비교에 집중하고 서울을 고정 첫 행으로 유지합니다.
**범위:** index.html, src/app.js, src/styles.css, 신규 src/clock-state.js, 브라우저 번들, 관련 테스트와 현재 사용 문서.
**접근:** 그룹·홈 지정·이름/업무시간 설정·일정·캘린더·공유·설정 창을 실행 화면과 번들에서 제거합니다. 도시 검색·추가·삭제·순서 조정, 날짜 이동, 12/24시간 표시, 현재 시각과 시간 칸 비교만 유지합니다. 서울은 삭제/이동할 수 없습니다. 과거형 데이터는 기존 키에 보존하고 활성 그룹의 도시를 신규 단일 목록에 읽어 옵니다.
**화면:** 차콜 회색 바탕과 대비가 높은 글자, 최소 13px 보조 글자, 18px 시간 칸, 20px 도시명, 28px 시계. 마케팅 문구와 불필요한 여백을 제거하고 시간표를 중심으로 배치합니다.
**검증:** 고정 서울/이동/상태 검증/과거 데이터 보존을 테스트하고 번들을 재생성합니다. HTTP 개발 미리보기에서 주요 동작·데스크톱·모바일과 글자 대비를 확인합니다. index.html 직접 실행 구조는 유지하며 file: 브라우저 검증을 우회하지 않습니다.

사용자께서 제거할 기능과 서울 고정 규칙을 명확히 지정하셨으므로 해당 범위에서 진행합니다. 기본 색상은 제가 선택한 차콜 톤이며, 실제 화면 검수로 대비를 확인합니다. Git 커밋·푸시는 하지 않습니다.

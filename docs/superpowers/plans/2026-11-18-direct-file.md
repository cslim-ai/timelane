# index.html 직접 실행 계획

**목표:** Node.js와 서버를 실행하지 않고 index.html 더블클릭으로 기존 기능을 사용합니다.
**접근:** 개발용 ES 모듈은 유지하고 배포용 일반 스크립트 파일을 생성합니다. HTML의 자산과 처음 화면 링크는 상대 경로를 사용합니다. 공유 주소는 file:와 HTTP 모두 URL API로 구성합니다.
**범위:** index.html, src/app.js, src/state.js, assets/timelane.js, scripts/build-browser.mjs, 실행 스크립트, 테스트, README 및 검증 기록.
**검증:** 번들 실행/격리/지원하지 않는 구문/산출물 최신성 테스트와 file: 공유 주소 회귀 테스트, 기존 전체 테스트, 실제 file:/// 경로의 검색·구간 선택·저장·공유·ICS·설정 가져오기 확인.
**제약:** 파일 실행의 저장·클립보드 정책은 브라우저에 따라 다릅니다. 기존의 저장 오류 안내와 수동 복사 대체 기능을 유지합니다. 기존 HTTP 주소의 저장 데이터는 자동으로 읽을 수 없으므로 JSON 백업/가져오기로 옮깁니다.

- [x] 실행 문서와 검증 기록 갱신

사용자가 직접 실행 방식으로 변경하고 진행하도록 명시했으므로 별도 승인 단계 없이 현재 세션에서 구현합니다. Git 커밋·배포는 하지 않습니다.

결과: 전체 테스트 38개 통과, 실행 파일 최신성/문법 검사 통과. 독립 코드 리뷰 후 저장소 차단 시 설정 가져오기도 탭에서 동작하도록 보완했습니다. 기존 및 검증용 Node.js 서버를 종료했습니다. 실제 파일 주소 브라우저 실행은 정책상 확인할 수 없었습니다.

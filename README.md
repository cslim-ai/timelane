# TimeLane

서울을 기준으로 세계 시간을 나란히 비교하는 간단한 로컬 웹앱입니다.

## 실행

`D:\Projects\TimeLane\index.html`을 더블클릭하세요. Node.js, 서버, 설치, 계정은 필요하지 않습니다. `start.cmd`와 `start.ps1`도 같은 파일을 기본 브라우저에서 엽니다.

`index.html`, `assets`, `src`의 폴더 구조를 유지해 주세요. 다른 컴퓨터로 옮길 때는 TimeLane 폴더를 통째로 복사합니다.

## 사용

- **서울은 기준 도시로 항상 첫 행에 고정**됩니다. 서울을 삭제하거나 이동할 수 없습니다.
- 검색창에 한국어·영문 도시 이름 또는 IANA 시간대를 입력하고 결과를 선택해 추가합니다. 서울을 포함해 최대 20개 도시를 표시합니다.
- 다른 도시의 × 버튼으로 삭제하고 ↑·↓ 버튼으로 순서를 조정합니다. 첫 번째 위치는 서울을 위해 고정되어 있습니다.
- 상단의 **서울 현재 시각**은 초 단위로 갱신됩니다. 12/24시간 형식을 선택할 수 있습니다.
- 처음에는 현재 시간 칸을 가운데에 두고 앞뒤 시간을 표시합니다. 현재 시간 열은 반투명한 붉은색으로, 정확한 시각은 그 안의 세로선으로 표시합니다. 시간표를 왼쪽으로 끌면 이후 시간, 오른쪽으로 끌면 이전 시간이 보입니다.
- 시간 칸을 가리키면 각 도시의 같은 순간을 도시 이름 오른쪽에 표시합니다. 클릭하면 해당 시각이 가운데로 이동하고 비교가 고정됩니다. 상단 서울 시계는 비교 중에도 실제 현재 시각을 표시합니다. **현재로**를 누르면 시간표가 현재 시각으로 돌아옵니다.
- 날짜 선택과 날짜 옆 화살표로 다른 날을 열 수 있습니다.
- 시간표 색상은 각 도시의 현지 시각에 따른 낮(07~18시), 저녁(18~22시), 밤(22~07시)을 나타냅니다. 천문학적인 일출·일몰 계산은 아닙니다.
- 키보드 `/`로 검색창을 열고 방향키·Enter로 도시를 선택합니다. 시간 칸에서는 ←/→, Home/End로 이동하고 Enter/Space로 해당 시각을 가운데에 고정합니다. Esc로 비교와 검색을 해제합니다.

그룹, 기준 도시 변경, 이름·업무시간 설정, 일정·캘린더·공유 기능은 현재 화면에서 제공하지 않습니다.

## 화면과 저장

차콜 회색 배경과 대비가 높은 글자를 사용합니다. 도시 이름과 국가를 왼쪽에, 시각과 날짜를 그 오른쪽에 표시합니다. 데스크톱에서는 도시명 20px, 도시 시각 24px, 시간 칸 18px, 보조 글자는 최소 13px입니다. 화면 너비에 따라 표시할 시간 칸 수가 달라집니다.

도시 목록과 표시 형식은 브라우저의 `timelane.clock.v2` 저장 항목에 보관합니다. 재방문 시 서울 현재 시각을 가운데에 표시합니다. 현재 시각을 따라가는 동안 시간이 바뀌면 시간표도 이동합니다. 특정 시각을 비교하거나 이전·이후 시간표를 열어둔 동안에는 보고 있던 범위를 유지합니다.

이전 버전의 활성 그룹에서 도시 목록을 읽어 서울을 첫 번째에 배치합니다. **이전 `timelane.v1`의 그룹·일정 데이터는 삭제하거나 덮어쓰지 않습니다.**

파일 실행의 저장 정책은 브라우저에 따라 다릅니다. 파일 경로나 브라우저가 바뀌면 설정이 자동으로 이어지지 않을 수 있으며, 저장소 사용이 차단되면 현재 탭에서만 유지된다는 안내를 표시합니다. HTTP 미리보기와 파일 실행도 저장 공간이 다릅니다.

시간 계산은 브라우저의 IANA 시간대 데이터와 기기 시계를 사용합니다. 서머타임과 30분·45분 시차를 반영합니다. 비교 날짜는 1900~2100년이며, 과거 일부 초 단위 시차는 분 단위로 반올림합니다.

## 개발용 검증

앱 사용에는 필요하지 않습니다. 개발과 테스트에는 Node.js 22 이상을 사용합니다.

```powershell
node scripts/build-browser.mjs
node scripts/build-browser.mjs --check
node --test
```

실행 번들은 `src/time.js`, `src/locations.js`, `src/clock-state.js`, `src/app.js`로 구성됩니다. `src/*.js`를 수정했다면 `assets/timelane.js`를 다시 생성합니다. 과거 버전의 상태·일정 모듈과 테스트는 원본 보존용으로 남아 있으며 현재 실행 번들에는 포함하지 않습니다.

화면 검수가 필요하면 선택적으로 `node server.mjs`를 실행하고 [개발 미리보기](http://127.0.0.1:4317)에 접속할 수 있습니다. 이 개발 서버는 루프백 주소에서만 동작하며 종료는 Ctrl+C입니다. 일반 사용자는 index.html만 열면 됩니다.
